# Source of the place table

`de-places.tsv` (postal code, place name, latitude, longitude, tab separated) is derived from the GeoNames postal code file for Germany, `DE.txt` from https://download.geonames.org/export/zip/DE.zip, downloaded on 2026-11-24. Only four of its columns are kept.
