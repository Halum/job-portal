# Bambase has a fixed host and is scheduled by its interval alone

The bambase source scrapes the one public listing page at `https://bambase.de/jobs`. The host is a constant in the module (no configuration or page content picks where a request goes), every request carries a 30 second timeout, and the clock for the relative ages ("vor 2 Tagen") is a parameter so tests stay deterministic. The listing has no search criteria, so no query variable exists: the worker schedules the source when `BAMBASE_INTERVAL_MINUTES` (integer, at least 1, empty counts as unset) is set, and each source keeps its own interval. A listing card without a title is reported as a Run error and the rest of the page is kept. The fixture is the old portal's recorded page reduced to the listing cards, with titles, employers, locations, slugs and descriptions replaced by placeholders (employer phone numbers and links in the descriptions were dropped), as ADR 0004 requires for this public repo.
